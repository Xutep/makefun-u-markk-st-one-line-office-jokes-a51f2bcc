## The joke

> The printer jammed again, so I reported it to HR for creating a hostile work environment.

## How it works

`main.py` (stdlib-only, deterministic) writes that single line to `/output/entry.txt`.
It is 89 characters — inside the 1–199 character gate — one line, about a real
office detail (the printer that always jams at the worst moment), with the laugh
landing in the last few words.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```

Run it twice and the output is byte-identical.
